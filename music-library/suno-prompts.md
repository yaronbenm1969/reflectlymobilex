# Suno Prompts — 100 טרקים לספריית Reflectly

## הוראות שימוש
1. פתח Suno → Custom Mode
2. הכנס את הפרומפט בשדה "Style of Music"
3. השאר שדה Lyrics ריק (Instrumental)
4. שמור את הקובץ בשם: `track-001.mp3`, `track-002.mp3` וכו׳
5. העבר לתיקיה: `music-library/tracks/`
6. עדכן סטטוס ב-catalog.csv → "נוצר בסונו"
